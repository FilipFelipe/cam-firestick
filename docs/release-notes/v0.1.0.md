# cam-firestick v0.1.0

**English** · Português abaixo

First public build of **Central de Câmeras**, a live RTSP security-camera wall for Fire TV.

> **Disclaimer:** provided **as is, without warranty of any kind**. Use it at your own risk; the author is **not responsible** for any damage, data loss or security issue. **Only tested on a Fire TV Stick HD (AFTSS, Fire OS 7) via sideload.**

**Highlights**
- Paged grid with up to 4 live cameras per page; the layout adapts per page (1 fullscreen, 2 split, 3–4 2x2).
- Audio follows the focused camera. OK opens fullscreen on the main stream while other cameras go to standby.
- Tour mode, by page or by camera.
- Setup from your phone via QR code: network scan, default login, pages, order and rotation.

**Install:** see the README (Downloader app or ADB).

# cam-firestick v0.1.0 (Português)

Primeira versão pública do **Central de Câmeras**, uma central de câmeras RTSP ao vivo para Fire TV.

> **Aviso:** fornecido **como está, sem nenhuma garantia**. O uso é por sua conta e risco, e o autor **não se responsabiliza** por danos, perda de dados ou problemas de segurança. **Testado apenas num Fire TV Stick HD (AFTSS, Fire OS 7) via sideload.**

**Destaques**
- Mosaico em páginas com até 4 câmeras ao vivo; o layout se adapta a cada página (1 tela cheia, 2 dividida, 3–4 em 2x2).
- O áudio segue a câmera focada. O OK abre a tela cheia no stream principal, e as outras câmeras entram em standby.
- Ronda, por página ou por câmera.
- Configuração pelo celular via QR code: busca na rede, login padrão, páginas, ordem e rotação.

**Instalação:** veja o README (app Downloader ou ADB).
